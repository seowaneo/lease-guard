# 계약돋보기 — 전세계약 점검 도우미 (MVP)

교육·정보 제공용 프로토타입입니다. **전세사기 여부를 판정하거나 보증금 반환을 보장하지 않습니다.**

## 포함된 기능
- 계약서 텍스트 직접 입력 및 가상 예시 불러오기
- 텍스트 PDF 추출 (PDF.js CDN), 사진 OCR (Tesseract.js CDN · 한국어)
- 규칙 기반 위험 특약 6종 탐지와 원문 인용 / 근거 설명
- 선택형 주택·재정 정보 입력과 참고 비율 계산
- 필수 외부 확인사항 목록, 결과 인쇄·PDF 저장
- GitHub Actions 테스트 및 GitHub Pages 자동 배포

## 실행

Node.js 22 이상 권장. 별도 npm 패키지 설치 불필요.

```bash
npm test
npm run build
npm run dev
```

브라우저에서 `http://localhost:5173`로 접속합니다. 문서 분석 라이브러리를 CDN에서 받아오기 때문에 PDF/OCR을 사용할 때는 인터넷 연결이 필요합니다.

## GitHub Pages 배포

1. 이 폴더의 파일 **전부**를 새 GitHub 저장소의 루트에 업로드합니다. `.github/workflows/deploy.yml` 경로를 보존하세요.
2. 기본 브랜치를 `main`으로 설정합니다.
3. 저장소 `Settings → Pages → Build and deployment → Source`에서 `GitHub Actions`를 선택합니다.
4. `Actions` 탭의 `Test and deploy to GitHub Pages` 작업이 완료되면 Pages URL을 열어 확인하세요.

별도의 API 키, 서버, 환경변수가 필요하지 않습니다. 정적 웹사이트이므로 GitHub Actions가 이용자 문서를 분석하지는 않습니다.

## 프라이버시

문서 파일과 입력한 재정정보는 이 앱 코드에 의해 서버로 전송되거나 서버에 저장되지 않습니다. 하지만 PDF.js와 OCR 프로그램 및 언어 데이터를 외부 CDN에서 불러오며 Google Fonts에 접속할 수 있습니다. 외부 리소스 호출 자체를 완전히 없애려면 향후 해당 라이브러리 및 폰트를 직접 호스팅해야 합니다. 브라우저의 확장 프로그램이나 기기 보안 상태까지 보장하지는 않습니다.

실제 계약서의 이름·주민번호·계좌번호 등은 가리고 사용하세요. GitHub 저장소나 이슈에 계약서 파일을 올리지 마세요.

## 한계 및 다음 단계

- 1차 MVP: 한글 텍스트가 포함된 PDF / 단일 사진 OCR만 지원. 이미지로 된 스캔 PDF에는 텍스트 직접 입력 또는 페이지 이미지로 변환하는 대안이 필요.
- 위험 탐지는 검증 전 규칙 6개에 한정되므로 거짓 음성/양성이 가능합니다. 실제 판례·법률 전문가 교차검토가 필요합니다.
- 주택 가격 대비 채권 비율은 **경매 배당 예측이 아닙니다.**
- 법령·판례에 관한 정확한 날짜별 적용과 공식 출처 메타데이터, 법률 개정 업데이트는 2차 작업입니다.
- 사용자 파일 저장, 로그인, API 키, 임대인 정보 자동 조회는 구현되지 않았습니다.

## 프로젝트 구조

- `public/index.html`: UI
- `public/style.css`: 디자인
- `public/app.js`: 화면 로직, 파일 추출
- `src/rules.js`: 규칙 기반 분석 모듈 (배포 시 `dist/src`에 복사)
- `tests/rules.test.js`: 분석 엔진 테스트
- `scripts/build.js`: 정적 빌드
- `.github/workflows/deploy.yml`: 테스트·배포
